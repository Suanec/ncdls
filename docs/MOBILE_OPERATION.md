# iPhone 操作指南：从主页进入游戏并保存离线版

日期：2026-11-24。按 iPhone + Safari 编写，具体按钮位置随 iOS 布局略有不同。

## 地址和部署结构

- 个人主页：<https://suanec.github.io/>。
- 游戏地址：<https://suanec.github.io/ncdls/>。
- 游戏代码及部署：[Suanec/ncdls](https://github.com/Suanec/ncdls)。
- 主页仓库：[Suanec/suanec.github.io](https://github.com/Suanec/suanec.github.io)。仅在 `_data/navigation.yml` 增加“挪车打螺丝”入口，不复制游戏资源进去、不更换原主页。

游戏入口固定为 `https://suanec.github.io/ncdls/`，每次发布更新同一地址，不需要修改书签或手动添加版本号。`?v=...` 不是历史版本选择器，也不会单独生成存档。普通在线页面刷新后获取新版；保存过离线包时按本文“后续更新游戏”操作。

游戏独立部署在 `/ncdls/`。它的 Service Worker 和离线资源缓存只覆盖该目录，不接管主页及其他项目页面。浏览器 `localStorage` 按同源共享，游戏使用自己的 `user_json_ncdls_web` 键。

## 更新卡住、加版本号也仍显示旧版

直接打开 [恢复入口](https://suanec.github.io/ncdls/recover.html)，点“保留存档，打开最新版”，之后在“选择关卡”确认 `20261125.2`。会保留关卡存档和已下载资源，从当前关卡开始在线玩；不用先完成整个离线包。需要离线时再点“保存离线资源”。见 [具体原因和恢复步骤](UPDATE_RECOVERY.md)。

## 第一次在手机上打开

1. 手机连一个能访问 GitHub Pages 的网络。可以是 Wi-Fi，也可以是蜂窝网络，**不需要和电脑连同一个 Wi-Fi**，电脑也不需要启动 Node 服务。
2. 打开 **Safari**。不要停留在微信、聊天软件的内置网页中。
3. 在 Safari 地址栏粘贴 `https://suanec.github.io/ncdls/`，点“前往”。也可先打开个人主页，再点“挪车打螺丝”；窄屏导航可能折叠到菜单中。
4. 页面先显示进度条，再下载运行文件和本关资源。运行文件阶段分别标注“正在下载运行文件”或“正在读取本机缓存”，并显示对应读取量和百分比，本关资源阶段显示已完成项数；超过 12 秒没有新进展会提示检查网络或重新加载。加载完成后确认看到游戏。此时可以联网玩，但尚未保证断网可玩。
5. 若需要选关，点右下角“选择关卡”，选择玩法和关数，再点“进入关卡”。这会修改当前浏览器的对应进度。

看到 GitHub 仓库的文件列表，说明打开的是 `github.com`，请改用上面的 `suanec.github.io/ncdls/`。`127.0.0.1:8091` 是电脑本地开发地址，不是手机访问地址。

## 添加到主屏幕

1. 保持 Safari 停在**游戏页面**。不要把个人主页添加成游戏图标。
2. 点“分享”（方框向上箭头）。部分布局需要先点地址栏旁的页面菜单，再点“共享”。
3. 在分享列表向下找 **“添加到主屏幕”**。没看到时到列表底部“编辑操作”中添加该选项。
4. 名称可保留“挪车螺丝”。如果出现 **“作为网页 App 打开”**，保持开启，然后点“添加”。
5. 回到手机主屏幕，点新出现的游戏图标。

操作依据：[Apple：在 Safari 中将网站变为 App](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)。

## 把资源保存到手机

1. **从刚才添加的主屏幕图标打开游戏**。
2. 点游戏左下角 **“离线与存档”**。
3. 点 **“保存离线资源”**。
4. 保持联网、页面在前台，先不要锁屏。等待全部资源下载，约 44.4 MiB；手机实际存储占用略大。
5. 直到出现 **“离线资源已就绪”** 再关闭菜单。仅打开过一关、仅添加了主屏幕图标，都不等于完成离线下载。
6. 下载中断或失败时，恢复网络后再点一次下载按钮；已完成的同版本资源会复用。

## 验证以后不需要网络

1. 确认已显示“离线资源已就绪”。
2. 打开飞行模式，并确认 **Wi-Fi 和蜂窝网络都已关闭**；部分手机会保留飞行模式下的 Wi-Fi。
3. 从 App 切换器退出游戏，再从主屏幕图标重新打开。
4. 确认能进入关卡，再通过“选择关卡”换一种玩法试一下。
5. 都正常后，说明离线包已可用。以后可直接从图标打开，电脑关机也可以玩。测试完成后可恢复正常网络。

当前提供经典、星星、海洋、冰雪、哪吒五种玩法，共 393 条关卡配置。未补齐猫咪、打巨龙和其他缺失资源。

## 查看和备份进度

1. 从游戏图标打开，点“离线与存档” → **“查看存档”**，即可看到 JSON。
2. 点 **“导出存档”**，将生成的 `ncdls-save-YYYY-MM-DD.json` 存到“文件”App。Safari 的下载入口和分享入口可能随版本变化。
3. 在另一台设备打开同一游戏，点 **“导入并重启”**，选择该 JSON。它会替换那台设备的当前进度，并从相应关卡开始。

`localStorage` 不是文件名，浏览器内的存档键是 `user_json_ncdls_web`；只有手动导出才生成可见 JSON 文件。经典关卡进度在 `total_type.grade`。

电脑本地地址、局域网 IP、GitHub Pages 地址不是同一个来源，存档不会自动迁移。电脑和手机也不会自动同步。Safari 普通页面与主屏幕应用的数据共享行为可能受 iOS 版本影响；以从主屏幕打开后看到的进度为准，需要时用导入导出迁移。原网页版的控制台导出方法见 [手机工程 README](../web_mobile/README.md#查看备份和迁移存档)。

清理网站数据可能同时删除存档和离线资源；手机存储紧张时浏览器也可能回收资源。因此长期进度建议导出备份。重启电脑上的静态服务不影响手机存档。

## 为什么每次进入仍有进度条

`20261125.1` 起，默认按需加载也会保存下载过的文件，再次进入优先读取本机。进度条仍会出现，因为需要读取代码、初始化引擎、构建关卡；“正在读取”不代表重新下载。新增关卡需要的资源、内容有变化的更新，以及被浏览器清理的文件仍需联网获取。手动“保存离线资源”负责补齐全部关卡。详见 [缓存说明](LAZY_CACHE.md)。

## 默认加载与完整下载

`20261124.3` 起：直接打开游戏默认加载引擎和当前关卡所需资源；进入其他玩法时再请求对应资源。首次仍需要下载必需的引擎脚本和配置，并非零下载。未点击下载按钮时，不会下载全部约 44 MB 离线包。

要完整下载：点“离线与存档 → 保存离线资源”（已有离线包时显示“检查并下载更新”），等待全部 1,901 个文件校验完成。之后可断网游玩。浏览器自动检查更新不触发全量下载；旧完整离线包会保留到手动更新，哈希相同的资源会复用。

旧版离线页面如果只出现“应用更新并重启游戏”，点击也会先补齐新版本再应用，不需要删除网站数据或存档。重新打开选关菜单，确认版本为 `20261125.2`。

## 下载特别慢时

`20261124.4` 改为 21 个资源包传输，解包并校验后保存到手机。旧版正在下载时，关闭当前游戏标签页，再用 Safari 打开固定入口，点击“离线与存档 → 检查并下载更新”。已保存且校验一致的资源会复用，不要先清网站数据。完成后点“应用更新并重启游戏”。具体前后耗时、进度含义和网络限制见 [下载速度说明](DOWNLOAD_PERFORMANCE.md)。

## 画面掉帧但还可以玩

连续玩十秒左右，点“选择关卡 → 检测卡顿（保留现场）→ 复制诊断摘要”。摘要保存打开菜单前的最近帧率、最长帧间隔、引擎主线程执行耗时和低帧率开关。完整记录可用“导出完整诊断文件（可选）”，无需复制大段 JSON。数据解释见 [性能诊断](PERFORMANCE_DIAGNOSTICS.md)。

## 车辆和掉落卡片一起卡住时

1. 保持卡住的页面，先不要刷新或切关，以免丢失现场。
2. 点“选择关卡 → 检测卡顿（保留现场）”，等待约一秒。
3. 点“复制诊断摘要”（不超过 600 字），粘贴回聊天，并说明关卡和卡住前的操作。如果浏览器不允许自动复制，长按下面文本框全选复制。
4. 检测只读取状态，不重开游戏。需要继续玩时，再使用下方的重启按钮；重启仍会回到本关开始。

菜单应显示版本 `20261125.2`。有离线包的设备先按“后续更新游戏”升级。排查记录见 [卡顿诊断说明](FREEZE_DIAGNOSTICS.md)。

## 画面异常时重启

1. 点右下角 **“选择关卡”**。
2. 点 **“重启游戏（保留存档）”**，等待重新进入。会重建游戏引擎和绘图环境，回到当前玩法的当前关卡开始。
3. 若提示绘图环境中断，也可直接点提示下的同名按钮。

这不会删除 `localStorage` 存档或离线资源。关内车辆移动位置不是完整存档，重启后重新开始该关。没有看到此按钮的离线旧版，先按下节“检查并下载更新 → 应用更新并重启游戏”升级；在线版可刷新 Safari 页面。重启电脑上的 Node 服务不能重建手机里的绘图环境。

## 清除缓存与存档的区别

- **只重启绘图环境**：使用上面的重启按钮，进度和离线包保留。
- **更新旧资源包**：使用“离线与存档 → 检查并下载更新 → 应用更新并重启游戏”，保留进度。
- **清除网站数据**：先“离线与存档 → 导出存档”，再退出游戏。iPhone 前往“设置 → App → Safari 浏览器 → 高级 → 网站数据”，找到 `suanec.github.io`（可能按 `github.io` 归组）并删除对应项。旧版 iOS 在“设置”首页直接进入 Safari。只删除目标站点即可，避免使用“移除所有网站数据”影响其他网站。参考 [Apple 网站数据操作说明](https://support.apple.com/zh-cn/105082)。

删除网站数据会影响同源网站的数据，包括游戏存档和离线资源；不是只清图片。之后联网重新打开游戏，按需导入备份、重新保存离线资源。Safari 与主屏幕应用的存储行为受 iOS 版本影响，清理后应从实际游玩的入口确认。清缓存是排除旧版本的方法，不代表车辆漏画问题已修复。

## 后续更新游戏

1. 手机恢复联网，从主屏幕图标打开。
2. 点“离线与存档” → **“检查并下载更新”**。
3. 如果提示新版本已下载，点 **“应用更新并重启游戏”**。
4. 重新看到“离线资源已就绪”后，可以再次进行飞行模式冷启动测试。

版本更新保留浏览器存档，但重启会回到本关开始，不恢复正在操作的完整盘面。

## 打不开时怎么判断

| 看到的情况 | 下一步 |
| --- | --- |
| 局域网 `172.x` 或 `192.168.x` 地址不通 | 改用 `https://suanec.github.io/ncdls/`，不再依赖电脑局域网服务。 |
| 个人主页和游戏网址都连接超时 | 手机当前网络无法访问 GitHub Pages；换一个可访问的网络后完成首次安装。复制地址能减少输入错误，但不能解决网络不可达。 |
| 主页能开，游戏地址 404 | 核对 `/ncdls/` 拼写，查看下方部署任务是否成功。新部署可能尚未刷新。 |
| 出现 GitHub 文件列表 | 打开了源码仓库；请用 `github.io` 游戏网址。 |
| 提示不能保存离线资源 | 检查是完整 `https://` 游戏地址，并在 Safari/主屏幕应用中打开。 |
| 下载失败或一直停在某个进度 | 保持前台、确认网络和手机剩余空间，恢复后重试。没有出现“离线资源已就绪”前先不要断网。 |
| 飞行模式打不开 | 联网后从主屏幕图标进入，检查资源状态并补齐；不要先清理网站数据。 |
| 从第 1 关开始 | 当前设备或来源没有原存档；从旧地址导出，再在当前游戏导入。 |
| 添加图标后还是个人主页 | 添加了错误页面；先在 Safari 打开 `/ncdls/` 再添加游戏图标。 |

复制代码、ZIP 或工程目录到“文件”App，不能让当前多文件版本直接在 Safari 中离线运行。这个版本需要首次通过 HTTPS 下载；完成后才不依赖站点在线。

## 维护者：部署和主页链接

游戏发布工作流：`../.github/workflows/deploy-mobile-pages.yml`。

1. 在 [游戏仓库 Pages 设置](https://github.com/Suanec/ncdls/settings/pages) 中，将 **Build and deployment → Source** 设为 **GitHub Actions**。只修改游戏仓库的设置。
2. 推送游戏相关更改到 `main` 后，工作流自动重新构建、验证离线清单，且只上传 `web_mobile/dist/`。不把工程根目录或原始提取包作为网站内容发布。
3. 到 [Actions](https://github.com/Suanec/ncdls/actions) 查看 **Deploy mobile game to Pages**。只有 build、deploy 都成功才算部署完成；也可在该工作流页面点 **Run workflow** 手动部署。
4. 在 Pages 设置的 **Visit site** 打开实际发布地址，确认游戏可加载。
5. 主页仓库仅追加以下导航项，原来的主题、内容、构建设置和导航项保留：

```yaml
  - title: "挪车打螺丝"
    url: /ncdls/
```

这是公开网站入口，访客可访问游戏资源；个人存档仍在自己的设备浏览器中。无需安装微信开发者工具或自行管理 HTTPS 证书。

GitHub 文档：[Actions 部署 Pages](https://docs.github.com/en/get-started/start-your-journey/deploying-your-website-automatically)、[Pages 的 HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https)。

本机已完成 Chrome 手机视口下的离线冷启动、五种玩法抽样、存档导入导出和缓存更新验证；不代表 iPhone 真机已验证。请按本文完成一次手机飞行模式测试。
