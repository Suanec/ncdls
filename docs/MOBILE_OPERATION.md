# 手机操作

入口：[挪车打螺丝](https://suanec.github.io/ncdls/)。当前版本看 [README](../README.md)，进入游戏后也可在“选择关卡”查看。用线上地址无需电脑开机或与电脑连接同一 Wi-Fi。

## 第一次打开

1. 用 Safari 打开游戏地址。微信内置浏览器不作为离线安装入口。
2. 本机没有游戏资源时，选择“按需加载，先开始玩”或“一次下载全部资源”。前者先下约 9 MB 运行文件和本关资源；后者等当前构建的全部约 45 MB 资源保存完再进入。
3. 已有缓存时直接复用，不再询问。画面出现后可点车游玩；右下角“选择关卡”可选择玩法和关数，会更新对应进度。
4. 想从主屏幕打开：Safari 分享 → 添加到主屏幕，添加的是游戏页面，不是个人主页。

按需加载不保证未访问过的关卡能离线玩；进度条出现也不一定代表下载。以“网络下载 / 本机缓存 / 解析与创建场景”提示区分，详见 [资源加载](RESOURCE_LOADING.md)。

## 桌面图标与震动

`20261126.2` 起桌面图标为浅蓝底红色小汽车。更新游戏后，用 Safari 打开正式入口，再“分享 → 添加到主屏幕”，确认预览出现小汽车再添加。图标来自游戏素材，无需等待全部关卡资源下载。

旧主屏幕图标可能仍保留旧图片，不保证随网页更新立即替换。若要删除旧主屏幕应用后重加，先从旧入口导出存档；确认新入口进度正确后再清理旧图标，不要为换图标清除 Safari 网站数据。

游戏齿轮设置中的震动开关可切换并保存，但无论开或关，都不会调用设备震动；车辆碰撞等画面抖动动画仍按原玩法运行。

## 完整下载与离线验证

1. 从之后实际使用的入口打开游戏（Safari 或主屏幕图标）。
2. “离线与存档” → “保存离线资源”，保持联网、页面在前台，等待“离线资源已就绪”。首次已选全部下载且显示就绪时，不必重复下载。
3. 断网后退出再重新打开，并换关验证。测试时同时关闭 Wi-Fi 和蜂窝网络。
4. 中断后恢复网络重试，已校验文件会复用。只添加图标不等于下载完成。

完整包只包含当前工程已有资源；猫咪、打巨龙与缺失房间不在承诺范围。浏览器可能因空间不足或清理网站数据回收缓存，因此仍应备份进度。

## 存档：查看、备份、迁移

“离线与存档”中可“查看存档”“导出存档”“导入并重启”。导出文件名为 `ncdls-save-YYYY-MM-DD.json`；导入会替换当前进度，从对应关卡开头开始。

- 存档在浏览器 `localStorage`，键为 `user_json_ncdls_web`；经典关卡字段为 `total_type.grade`。
- `localStorage` 不是工程里的某个文件。只有手动导出后，才有可见的 JSON 文件。
- 重启静态服务器不删除存档；关内车辆、螺丝的完整盘面没有逐步保存。
- 协议、主机、端口不同是不同来源，进度不会自动迁移；电脑与手机也不自动同步。Safari 与主屏幕应用以各自实际看到的进度为准。

电脑在实际游玩的地址打开开发者工具，可查看：

```js
JSON.parse(localStorage.getItem('user_json_ncdls_web'))
```

Chrome 的 Application → Local Storage、Safari 的 Storage → Local Storage 也可查看。手机版导入只接受“导出存档”生成的封装文件，不能直接导入上面读取出的原始 JSON；基础网页的原始值可自行留存，但不等于手机版导入文件。

## 更新、重启、恢复

| 需要做什么 | 操作与结果 |
| --- | --- |
| 更新完整离线版 | “离线与存档” → “检查并下载更新” → 提示完成后“应用更新并重启游戏” |
| 重建卡住/异常画面 | “选择关卡” → “重启游戏（保留存档）”；保留当前玩法和关号，从本关开头开始 |
| 更新卡住或一直显示旧版 | 原浏览器打开 [恢复页](https://suanec.github.io/ncdls/recover.html)，点“保留存档，打开最新版” |
| 查看卡顿原因 | 卡住后先不刷新，点“选择关卡” → “检测卡顿（保留现场）” → “复制诊断摘要” |

恢复页注销本游戏的旧缓存控制器，再在线打开当前版本；不会清除存档或已下载资源。`?v=...` 不能强制升级或选择历史版本。刷新整个网页可能回到默认玩法入口；菜单的“重启游戏”会额外恢复当前玩法和关号。

## 清除缓存与存档的区别

优先更新或重启，不需要为普通升级删除网站数据。确需清理 Safari 数据时，先导出存档，再进入“设置 → Safari → 高级 → 网站数据”删除目标站点；较新系统的 Safari 设置在“设置 → App”下。

网站数据清理会影响同源的存档与离线资源，不只是图片；`suanec.github.io` 下其他页面也可能受影响。清理后联网重开，按需导入存档和重新下载资源。

## 常见现象

| 现象 | 判断与处理 |
| --- | --- |
| 显示 GitHub 文件列表 | 打开了 `github.com` 仓库，应使用 `suanec.github.io/ncdls/` |
| 线上地址连接超时 | 换可访问该站点的网络；复制粘贴、加版本参数不能修复网络不可达 |
| 手机连本地地址失败 | 使用电脑 LAN 地址，不用手机的 localhost；检查设备隔离和防火墙 |
| 9 MB 下载完仍加载 | 运行代码已到达，还需本关模型、图片、解析和场景创建 |
| 下次又有进度条 | 先看来源标签；读取缓存和初始化也有进度，不代表重新下载全部 |
| “资源版本不匹配，正在更新” | 正在校验并补下载；持续失败时按页面提示重试 |
| 动画与车一起停住 | 保留现场复制诊断摘要，再重启；[故障记录](TROUBLESHOOTING.md)说明已知原因 |
| 重开从本关开始/换站后从第 1 关开始 | 前者是存档粒度，后者通常是来源变化；旧站导出后导入 |

手机飞行模式冷启动仍应在实际设备验证；桌面 WebKit 和手机尺寸视口不能替代每一种 iPhone/iOS 环境。
