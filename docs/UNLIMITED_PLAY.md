# 20261125.4：连续关卡与免费道具

正式入口：[挪车打螺丝](https://suanec.github.io/ncdls/)。网址不需要带版本号；在“选择关卡”查看版本。旧离线页可先通过 [在线恢复入口](https://suanec.github.io/ncdls/recover.html) 保留存档打开最新版。

## 选关与循环

五种玩法允许输入 1 到 9,007,199,254,740,991 的正整数（JavaScript 能精确保存的整数范围）。拒绝零、负数、小数和超出精确范围的数。模板数量如下：

| 玩法 | 模板数 |
| --- | ---: |
| 经典挪车 | 294 |
| 星星 | 12 |
| 海洋 | 27 |
| 冰雪 | 30 |
| 哪吒 | 30 |

对应模板：`(关卡号 - 1) % 模板数 + 1`。界面、关卡进度存档保留输入的完整关卡号，菜单实时提示使用哪套模板。

经典第 294 关通关后，进入第 295 关并使用模板 1；之后第 296 关使用模板 2。网页版取消了原游戏遇到模板 1 就额外跳一关的逻辑，295 不再缺号。模板 1 仅复用地图配置，教学引导仍只在真正的第 1 关触发。达到安全整数上限后通关不再增加，以避免存档数值失真。

更大的关卡号不会新增地图资源；原有配色、车辆及螺丝规则、随机逻辑保持不变。393 是五种玩法模板总数，不是无限套独立地图。

## 磁铁和刷新

- 两个道具均默认显示 **1**；旧存档原来为 0、99 等值时，打开游戏后也归一为 1。
- 成功使用后仍为 1，可再次使用；取消这两个按钮的每关使用次数上限。
- 两个按钮直接执行原道具效果，不进入领取弹窗、激励视频和广告曝光/点击/完成上报分支。
- 保留原动画与必要条件：动画尚未结束时暂不能重复触发；磁铁需要有未装满的等待车辆；刷新需要足够的同色空车，条件不足时仍显示原提示。
- 只调整磁铁和刷新；其他道具和第三方网络分支未做全局修改。

实现位于 `scripts/web-props-compat.cjs`，由网页构建应用于道具按钮类；原始小游戏源码与实际效果函数保持不变。转换锚点改变时构建失败，防止静默漏改。选关在 `web/launcher.js`，经典连续编号在 `web/browser.js`。

## 更新和验证

`.4` 运行包发生变化，需要下载一次约 9.3 MB；未变化的模型、图片继续复用缓存。按需加载和手动全量下载规则不变，也不清空存档。

自动检查覆盖五种玩法的大关卡号、取余提示、无效输入、跨模式重启恢复、294→295→296、安全整数边界，以及两个道具的旧存档归一、重复成功、失败与禁用、回调去重、没有广告调用。使用 `npm run check:mobile` / `npm run check:web` 运行。

Chrome 与 WebKit 均通过实际选关表单验证经典 294、295、296、588、589、1,000,000 关，及四种主题玩法的 1,000,000 关；哪吒第 1,000,000 关重启后仍使用模板 10。两种浏览器均实际触摸使用刷新 3 次、磁铁 2 次，全部成功、数量始终 1、广告调用 0，无运行错误或重复停绘。浏览器实测记录见 `reports/unlimited-play-*.json`，复测脚本为 `scripts/probe-unlimited-play.cjs`（需 Playwright 和对应浏览器）。桌面 Chrome / WebKit 使用手机视口测试，不等同于 iPhone 真机；`.3` 停绘和掉帧修复已获得用户真机确认，`.4` 保留该修复。
