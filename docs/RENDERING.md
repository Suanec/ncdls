## 当前修复：第一关模型实例被重复借出

在 Mac Chrome / Apple M4 Pro / WebGL 2 中直接访问线上第一关，已复现缺黄色车、车辆重叠和车位缺失。记录中黄色车和绿色车的 `sp3.id` 都是 `1827`；黄色车的坐标也被改成绿车的坐标。对象池 `gO()` 返回实例后，实例仍留在 `pool_set`（空闲集合），且 `u_set`（使用中集合）没有记录，因此下一个借用者再次拿到同一节点。车位也记录到连续返回同一实例。这个证据来自实际失败页面，不是根据浏览器版本猜测。

## 默认按需加载，按钮触发全部下载

首屏不再预创建数百个车辆/螺丝/特效实例，不预取暂未使用的音效、排行榜图集。必需运行时脚本并行下载、按原依赖顺序执行；模型和音效在玩法真正使用时加载。第一关游戏 iframe 实测资源请求由 158 次降为 134 次（同一统计口径，不计父页面）；父页面也不再自动请求完整离线清单。

默认进入第一关不会注册离线 Service Worker，也不会请求其他玩法包。点击现有“保存离线资源 / 检查并下载更新”按钮才下载完整的 1,915 个文件（约 44.4 MiB）。浏览器自动检查 Service Worker 更新仅安装更新脚本，不下载整包；等待手动操作时保留旧完整包。手动更新复用哈希一致的旧文件，完整包校验后再应用。旧缓存页面的“应用更新”协议也兼容。

必需引擎、业务脚本和共享配置仍需首次下载；第一关游戏 iframe 解压资源量约 11.5 MiB，不能把按需加载描述为几乎无需下载。完整离线包仍按用户要求保留，不删除资源。

## 历史尝试：20261124.1

1. 在 `web/browser.js` 的 `NCDLSWeb.start` 中、`new W.M2` 创建绘图环境之前设置 `Laya.Config.useWebGL2 = false`。统一使用原引擎已有的 WebGL 1 路径，作为当前浏览器兼容方案。未升级引擎或改动模型、关卡、车辆坐标。曾尝试的全局关闭静态/动态批量绘制方案没有足够证据，已撤掉。
2. “选择关卡”菜单加入“重启游戏（保留存档）”。重启会先保存进度，再卸载旧游戏 iframe，重新创建引擎，恢复当前玩法及关卡。当前盘面的车辆移动不作为完整快照保存。
3. 捕获 `webglcontextlost`，显示明确的重启按钮；不让玩家面对无提示的残缺画面。错误后也可从选关菜单重启。
4. 页面显示版本号，并为本次变更的入口脚本和样式加版本参数，减少 HTTP 缓存继续使用旧入口的问题。离线 Service Worker 仍需通过更新按钮升级，网址参数不会绕过旧离线缓存。

Laya 引擎维护者针对 2.13 和 iOS 15 的花屏问题建议关闭 WebGL 2，见 [Laya 官方社区记录](https://ask.layabox.com/d/50469)；[WebKit Safari 15 说明](https://webkit.org/blog/11989/new-webkit-features-in-safari-15/)记录了 WebGL 2 与 Metal 渲染后端的引入。它们为回退方案提供依据，但不等于已经证明本工程全部设备上的具体底层根因。

## 如何获得新版

打开游戏后，在“选择关卡”菜单确认版本为 `20261124.3`。正式入口固定为 [https://suanec.github.io/ncdls/](https://suanec.github.io/ncdls/)，发布会更新这个地址，不要求版本参数。`?v=20261124.3` 只是辅助刷新入口，不会锁定或切换到某个历史版本，不会分开存档，也不会绕过 Service Worker 离线包。已经保存离线包的设备，使用“离线与存档 → 检查并下载更新 → 应用更新并重启游戏”。

清理缓存、保留存档和彻底删除网站数据的区别见 [手机操作文档](MOBILE_OPERATION.md#清除缓存与存档的区别)。不需要重启 GitHub Pages 服务，也不需要清空存档才能应用新版。
