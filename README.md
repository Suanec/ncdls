# 挪车打螺丝学习工程

从微信客户端缓存整理出的 Laya 游戏，现有可运行的纯前端网页版。复用原玩法、关卡与资源，增加浏览器适配、选关、离线缓存和存档管理；没有恢复原始编辑器工程或服务端。

- **游戏入口**：[suanec.github.io/ncdls](https://suanec.github.io/ncdls/)
- **当前游戏版本**：`20261126.2`。
- **恢复基准**：标签 [`milestone-20261125.5`](https://github.com/Suanec/ncdls/tree/milestone-20261125.5)，游戏提交 `4401c38`。后续文档提交不改变此基准。
- **已知范围**：手机加载与画面、停绘及明显卡顿修复已获用户确认；不是所有设备、全部关卡均已验收。微信开发者工具工程仅做过静态检查。

本次更新：震动开关保留显示与保存，但不调用设备震动；桌面图标改用现有红色汽车素材，并在初始 HTML 中声明。此前音频失败保护继续保留。验证范围见 [故障记录](docs/TROUBLESHOOTING.md)。

## 运行

在工程根目录使用 Node.js 18+，无需 `npm install`：

```sh
npm run web       # 构建并启动基础网页版，http://127.0.0.1:8088/
npm run mobile    # 构建并启动带离线/存档菜单的版本，http://127.0.0.1:8091/
```

选择其中一个即可。手机直接访问线上入口不依赖电脑；局域网调试见 [开发与发布](docs/WEB.md)。不要双击 HTML 或将整个文件夹复制到 iPhone 后期待 Safari 直接运行。

## 当前行为

网页版开放经典、星星、海洋、冰雪、哪吒五种玩法，共 **393 套模板**；支持安全整数范围内的任意正整数关卡，循环复用模板。经典 294 → 295 → 296 连续编号。七个已有车位全部开放；磁铁与刷新显示 1，使用不扣除，并跳过这两个按钮的广告流程。

首次没有资源时可选按需加载或完整下载；下载过的文件可复用。存档键为 `user_json_ncdls_web`，保存在当前浏览器，记录进度而非完整盘面。重启会从本关开始；换设备或网址需要导出、导入存档。

## 维护入口

修改 `src/`、`web/`、`web_mobile/src/` 等源文件，再构建；不要直接编辑 `web-game/`、`web_mobile/dist/`、`wechat-game/` 等生成目录。`config/decoded/` 是阅读副本，修改它不会自动影响游戏。

```sh
npm run build:mobile
npm run check:mobile
```

缺失的猫咪、打巨龙及房间资源未补齐；“完整下载”指当前构建拥有的资源，不是原游戏全部远程内容。
